CS 210 Corner Grocer Project

Project Reflection

For my Corner Grocer project, I created a C++ program that reads grocery item
data from a file and keeps track of how many times each item appears. The main 
goal was to make it easier to look at the data and see which items were purchased
most often. This project helped me become more comfortable working with files, 
organizing data, and using different parts of C++ together. I think I did a good job
separating my code into different files and using functions to keep everything organized.
I also used a GroceryItem class, which helped me understand how classes and header files
work together. One of the more challenging parts was making sure the program read the 
data correctly and counted each item the right number of times. I used the course materials
to help me write the code and understand how the different parts worked together.

There are definitely things I could have improved if I went back and worked on this project.
For example, I could go back and improve the input validation and make the program handle
unexpected input a little better. This could help prevent errors and make the program more reliable.
I really tried to keep my code organized with separate files and descriptive names, which makes
it easier to go back and understand what each part does. The skills I learned from this 
project will help me with future programming assignments, especially when working with C++,
files, and data. I also learned that breaking a problem into smaller pieces makes it easier
to work through. In the future, I can use what I learned here to build programs that are more 
organized, easier to maintain, and simpler to update when new features are needed.
